# 자가발전 R5 — 타 프로그램 비교 갭 분석 (2026-07-03)

기준선: ① 감사 길잡이(자매앱) ② 상용 검증툴 패턴(ACL/IDEA·BlackLine·DataSnipper·GX — 증보 1차 §6.6) ③ 설계안 P0–P3.

## 감사 길잡이 대비

| 항목 | 감사 길잡이 | 재무감사 도우미 | 판단 |
|---|---|---|---|
| 검색 | 형태소·동의어 사전(norm_dict) | 제목 substring | **갭 — R7 후보**: 동의어 확장(성과급/성과상여금 등)은 재무 검색 품질에 직결 |
| 상세 열람 | 카드 전문(요지·위반사실·착안점…) | 제목+배지만(길잡이로 이동 유도) | 의도된 역할 분담(검색형↔절차형) — 유지 |
| 유사선례(CBR) | 있음 | 없음 | 역할 분담상 길잡이 몫 — 유지 |
| 오프라인(sw.js) | cache-first 서비스워커 | 없음 | **갭 — R8 후보**: 망분리 환경 가치 큼. Pages 배포 안정화 후 추가 |
| 온보딩 투어 | 있음(tour.js) | 게이트 화면이 사실상 온보딩 | 보류 — 화면 수 적어 과잉 |
| 다크·접근성 | KRDS 토큰 | 동일 토큰 상속 | 정합 |

## 상용 검증툴 패턴 대비(증보 §6.6 로드맵 준수 확인)

| 패턴 | 상태 | 비고 |
|---|---|---|
| 정합성 대사(cross-tie) | ✅ 등식 30종·예외 등록 | |
| 예외관리(BlackLine식) | ✅ 관리표(상태·메모·이력) | 경과일 필드는 ts만 저장 — 표시 개선 여지 |
| 감사조서화 | ✅ md 초안 생성 | HWPX 내보내기는 백로그(감문도 연계) |
| 증거연결(DataSnipper식) | 부분 — 원문상태 배지·근거조문 | 원문 파일 딥링크는 로컬 폴더 특성상 웹앱 한계(로컬 배포판 후보) |
| 전수검사·품질검사(ACL/GX식) | 계획대로 미구현(S4·파일 파싱 도입 시) | 증보 결정 유지 |
| 위험점수 | 부분 — 임계 판정·AR 위젯 | 합산 점수표는 후속 |

## 결정(자율)

- **R7 = 사례 검색 동의어 확장**(감사길잡이 norm_dict 재사용 — 인프라 공유 원칙): 다음 코드 라운드에서 구현
- **R8 = 서비스워커 오프라인**: Pages 배포 정상화 확인 후(캐시 버전 관리 포함)
- 나머지 갭은 의도된 역할 분담 또는 기존 로드맵과 일치 — 신규 작업 없음
