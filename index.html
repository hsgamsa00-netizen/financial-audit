개념 온보딩 — 최소 개념 세트

정합성 검산기 (cross-tie)

결산기준이 "일치해야 함"이라고 정한 등식을 결정론적으로 검산합니다(LLM 아님·항상 재현). 불일치 = 즉시 착안점 — 예외로 등록해 조서로 넘기십시오. 입력값은 이 PC에만 저장됩니다.

재무위험 스크리닝

임계값은 「지방자치단체 결산 통합기준」 재정위험 판단 지표의 원문 수치입니다. 판정은 감사 우선순위 신호일 뿐 위법·부적정 판단이 아닙니다.

⚠ 착시 경보 — 부채비율이 낮아져도 분모 증가(자산재평가·정부출자)가 원인이거나 수익성이 동반 악화면 "건전성 개선"이 아닙니다. 부채비율 하락 ≠ 부채 감소.
지표·배점 원문 참조(전체)

재무 사례 10,225 — 본문 열람

실제 감사 지적사례 10,225건의 본문(요지·위반사실·원인·착안점)을 앱 안에서 바로 열람합니다. 행을 클릭하면 상세가 열립니다. 요약카드이므로 금액·법조문 인용 전 원문 대조가 필요합니다.

계정과목 검증

회계 분류 트리에서 계정을 고르면 왜 위험한가 → 바로 할 일 → 필요자료 → 검증 테스트 → 오류패턴 → 조서 문안 순서의 검증 카드가 열립니다. 상세 근거(레시피 전문·기준조문·선례)는 펼치기 안에 있습니다.

처분수위 판단트리

발견사항의 검토 방향을 안내합니다 — 처분 확정이 아니며, 처분·지적에는 기준·원문·증빙·반론검토가 필요합니다. 시정 우선·변상 최후 원칙 내장.
